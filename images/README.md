# Images

Drop 10–15 images here. The script sorts them by filename and rotates through
them one per post, so name them `01-....png`, `02-....png` and so on to control
the order.

Supported: `.png` `.jpg` `.jpeg` `.webp` `.gif`

Keep each file under 5 MB (X's limit for images).

If this folder is empty, posts still go out — just without media.

## What works for this audience

Immigration attorneys are not impressed by generic AI art. Things that land:

- Clean product screenshots: the client-facing form, the branded theme picker,
  the generated PDF next to the web form.
- Before/after: a page of raw USCIS PDF beside the Mupler version of the same
  question.
- A single sentence set in large type on a flat background (pull one line out of
  a blog post).
- Simple flow diagrams: client link → filled form → exported PDF.

Avoid stock photos of handshakes and gavels.
